# Hero: центр Земли и компактная пауза

- Центр сцены вычисляется из реальных границ общей scenario-stack (две карточки и промежуток). Eyebrow, вкладки, disclaimer и controls исключены. Координаты переводятся в систему Hero; вычисление выполняется после fonts/layout/resize через ResizeObserver, не в ticker. Диаметр, география, shader и число точек сохранены.
- Единственная кнопка pause/play перенесена в строку «Пример автоматизации». SVG переключается по действующему состоянию паузы, aria-label/aria-pressed сохранены; target44×44px, focus-visible. Нижняя controls-разметка удалена, status остаётся доступным вне визуальной строки.
- Действующее заполнение, ритм6s, пользовательская пауза и повтор активной вкладки сохранены. В общей функции controls изменено только представление Hero; задачи используют прежний текст кнопки.

## Проверка
Свежая Vite-сборка успешна. Целевые Chrome viewport1440×900 и390×844: все шесть примеров, совпадение центра (отклонение меньше0,12px из-за округления CSS), прежний квадратный размер сцены806/436,8px, одна кнопка и отсутствие нижнего controls, Enter/pause/resume, повтор вкладки, отсутствие overflow и pageerror. Проверка не является повторной полной матрицей. Физические устройства не проверялись.

Mobile завершённая демонстрация снята обычным viewport после прокрутки к ней; дополнительный mobile-top.png снят при scrollY=0. Диагностические CSS не использовались.
