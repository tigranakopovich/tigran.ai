# Якорная навигация и компактность — локальный отчёт 11.10.2026

Preview: http://127.0.0.1:4176/?v=anchor-compact
Порядок: Hero → Проект → Задачи → Как работаю / контакт.

## Что изменено
- Устранено суммирование Lenis offset, CSS scroll-padding и scroll-margin. Единственный inset — измеренная высота fixed header +16px. ResizeObserver обновляет CSS scroll-padding; локальные ссылки используют ту же величину, числовую цель для Lenis и уточнение после смены высоты шапки. Меню, CTA Hero, стрелка, прямые hash-ссылки и reduced motion работают через согласованный механизм. Параметры колёсика/торможения/touch не менялись.
- Задачи: меньше padding/gap карточек, документов, сообщений, мобильных записей таблиц и вторичных элементов. Максимальная естественная высота всех десяти наложенных grid-сценариев по-прежнему задаёт стабильный резерв. Ни фиксированного обрезания, ни внутреннего скролла. Шрифты не уменьшались.
- Кейс и финал: сокращены только связанные вертикальные отступы. Контактный заголовок, поле и CTA сохраняют читаемость и воздух.

## Свежие проверки
Одна успешная сборка. Chrome1440×900 и390×844; на каждом размере14 переходов: меню, обе кнопки Hero, стрелка вниз и прямой #tasks с обычным motion/reduced motion. Прямой #project дополнительно снят обычным viewport. Конечная координата цели: desktop86px=70px шапка+16; mobile84px=68px+16 (округление менее1px). Заголовки доступны под шапкой. У близкого к концу страницы контакта возможна естественная граница максимальной прокрутки; контент видим.

Все10 задач: нет обрезки/overflow; высота workspace идентична между вкладками на каждом размере при обычном и reduced motion. Короткий пример — Статусы; самый высокий после уплотнения — Контент. В обоих размерах для каждого проверены полный15s проход до100%, повтор, повтор активной вкладки, остановка/продолжение. Тайминги/контроллер демонстраций не менялись.

Enter/Space раскрывают материалы кейса, поле бизнеса и контактная CTA доступны с клавиатуры. Текстовое заполнение поля проверено без реальных отправок. Console/page ошибок нет. Все8 снимков секций визуально просмотрены; они получены из full-page captures завершённых примеров при reduced motion, без диагностических CSS-изменений. Два дополнительных viewport-снимка показывают прямой переход к Проекту и fixed header.

## OPEN / ограничения
Для стабильности панели в коротких сценариях остаётся резерв самого длинного; без скачков высоты полностью убрать его невозможно. Длинные mobile-секции естественно занимают несколько экранов. Оригинальные материалы HP отсутствуют; прежнее предупреждение сохранено. Физические устройства/Safari, GPU-аудит, полная матрица и реальная передача в Telegram не проверялись в этом ограниченном проходе. Новых выявленных ошибок в назначенных проверках нет. SPEC, Земля/её позиция, стекло/цвета, тексты и контакты не менялись. Без установки, commit/push и публикации. Визуальную приёмку выполняет владелец по локальному результату.
