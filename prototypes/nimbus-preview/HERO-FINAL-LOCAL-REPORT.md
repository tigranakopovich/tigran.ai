# Hero — локальная финальная доводка

## Изменения
- Усилен тонкий холодный атмосферный край; широкий слабый halo вынесен в отдельный слой. Верх светлее, низ приглушён. Bloom и равномерное повышение яркости точек не добавлены.
- Начальный ракурс выбран по открытым участкам Hero: приблизительно 8°E / 8°S. География, число точек, shader и контроллеры сохранены. Статичный fallback синхронизирован с ракурсом.
- Общая высота результата сокращена с 256,6 до 220,3 px на desktop и с 341,8 до 300,8 px на mobile за счёт отступов и компактного размещения каналов. Текст и ритм заполнения сохранены; все шесть примеров имеют одинаковую высоту.
- Старый mobile.png был снимком элемента после прокрутки, а не viewport. Новый кадр — обычный 390×844 при scrollY=0, без диагностических CSS. Шапка сверху, поля 20 px, горизонтального переполнения нет.

## Проверки
- Production build Vite: успешно.
- Целевой просмотр 1440×900 и 390×844: завершённый пример, стабильная высота всех шести результатов, содержимое не обрезано.
- Reduced motion: статичный fallback доступен без инициализации GPU.
- Ошибок console/page в целевых проверках нет.
- SHA256 подтверждает сохранность контроллеров, данных, shader, маски и функции геометрии точек.
- Полная матрица размеров и длительные проверки повторно не выполнялись.
