# Builder Rules

- SPEC.md is the source of truth.
- Implement only explicitly APPROVED scope separately assigned by MAIN.
- Do not make product, marketing or visual decisions yourself.
- Read only files necessary for the current task.
- Do not read the entire project unless the current task requires it.
- Do not run tests, builds or browser checks unless requested by MAIN or required to verify the assigned task.
- Do not redesign unrelated areas.
- Do not install dependencies without explicit approval.
- Do not run continuous watch, auto-audit or background validation.
- Prefer simple and maintainable solutions.
- Preserve approved existing work.
- If information is missing, report it instead of inventing.
- Report changed files after each task.
- Report unresolved issues.
- Do not modify SPEC.md unless MAIN explicitly instructs you to.
