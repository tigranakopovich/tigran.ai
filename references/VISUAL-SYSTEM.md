## 3. Motion и взаимодействия — APPROVED обновлённый scope
Числа ниже — стартовые ориентиры для настройки, не неизменяемые tokens. Не добавлять взаимодействия, тексты или обещания. Ощущение качества создаётся единым easing, спокойным темпом и точными соединениями, не количеством эффектов.
Hero: медленное парение только входов 3–5 px, 7–10 s, разные фазы. Панель, copy и CTA стабильны. Один мягкий сигнал последовательно по связям и шагам, затем пауза; не несколько конкурирующих маршрутов. Связи прикреплены к карточкам при движении и resize. Mobile без постоянного парения; короткий однократный акцент допустим. Статичная схема всегда полная.
Задачи: native button «Посмотреть пример» в каждой строке; click/Enter/Space запускает один короткий проход исходные данные → обработка → заполненный результат. Одновременно один пример на всю секцию; новый запуск прекращает предыдущий и оставляет его корректное статичное состояние. Повторный запуск той же кнопкой, без клонирования DOM/таймеров. Итог остаётся; layout и focus не скачут. Нет реальных отправок и сетевых интеграций.
Этапы: hover, focus и click выделяют соответствующий компактный пример; mobile click. Список отметок, сигнал Telegram → n8n → AI → Google Sheets, проверка → исправление. Описания всегда видны. Клавиатурный выбор явным контролом с доступным названием этапа и выбранным состоянием; не превращать текст в скрытую кнопку. Не авто-листать; не открывать popup.
Кейс: один мягкий акцент связей/результатов при входе; текст, фото и таблица доступны сразу. Не скрывать результат opacity:0 до JS. После прохода полная схема. Без фиктивных действий.
Фон: допускается очень медленное движение малого числа слоёв только около схем. Mobile статичный фон; нет движения под copy/формой, animated blur, частиц или отдельного фонового шоу.
Контакт: фото, поле и CTA неподвижны; можно коротко акцентировать вход без задержки доступа. Состояния кнопок: согласованные hover/focus/pressed, ориентир 180 ms, без изменения размеров и смещения соседей.
Reduced motion: отключить парение, сигналы, появления, декоративное движение и smooth scroll; примеры по нажатию сразу показывают итог, этапы меняют статичное выделение. Текст и функции сохраняются.
Viewport/document visibility: декоративное движение остановлено вне экрана и при скрытой вкладке. Не запускать бесконечный JS tick для неподвижных блоков. Естественная прокрутка, нет scroll hijacking, звука, ожиданий. Никаких pointer tilt, sticky scroll-story или эффектов вне scope.
Производительность: предпочитать transform/opacity для движения, не анимировать размеры/позицию потока или большие фильтры; геометрию связей обновлять при resize, не измерять весь layout каждый кадр. Не устанавливать motion-библиотеки без явного одобрения. Резервировать размеры изображений, избегать layout shift. Технические способы Builder выбирает в пределах scope.
