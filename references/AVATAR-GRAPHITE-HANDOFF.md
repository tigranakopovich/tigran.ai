# Новый портрет Tigran AI

Дата: 04.10.2026. Подготовлен по прямому запросу владельца: фон и рубашка под новый graphite/glass дизайн. Результат для визуального просмотра владельцем, не отдельное поручение публикации.

- Оригинал: Avatar-original-2026-10-04.png — сохранённая копия C:/Users/Tigran/Pictures/Avatar.png.
- Производная: Avatar-graphite-shirt-v1.png — самостоятельный edited photo asset, не вырезка из UI mockup.
- Метод: встроенный imagegen, identity-preserving edit. Изменены фон и одежда; в задании закреплено сохранение лица, возраста, выражения, волос и естественной кожи. Генеративная обработка не является побитовым сохранением лица; итог показывается владельцу.
- Фон: нейтральный graphite/slate, мягкое отделение головы от фона, без зелёного/оранжевого оттенка.
- Одежда: тёмная slate рубашка без логотипов, открытый ворот, без галстука/пиджака.
- Производную дополнительно не перекрашивать CSS-фильтром и не генерировать повторно при реализации. Оригинал не перезаписан.

## Использование после выбора результата

Builder использует Avatar-graphite-shirt-v1.png как источник портрета; импортирует/оптимизирует средствами существующего проекта, не вставляет многомегабайтный оригинал. Сохранить aspect ratio; portrait frame object-fit:cover с фокусом на лице, object-position:center около40%. Desktop ширина128–144px как старт, mobile88px; не срезать волосы/подбородок. При viewport resize фото не должно растягиваться. Alt «Тигран», без animation/hover zoom.

В финальном сгенерированном референсе портрет показывает компоновку; production asset берётся из отдельной производной. Точные тексты контакта остаются из SPEC. Фото HP и Telegram composer — отдельные OPEN вопросы.

Референс контакта обновляется после создания standalone avatar, не до него. Prompt аватара и финального reference сохраняются отдельными .imagegen-prompt.txt. Сайт, production, зависимости и код в этом проходе не меняются.
