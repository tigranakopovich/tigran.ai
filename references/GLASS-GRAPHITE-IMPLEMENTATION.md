## 2. Стекло как материал

Панель: background rgba(32,38,48,.72–.84), border1px rgba(225,235,245,.16–.24), радиус18–22px; тонкий inset верхний свет и спокойная внешняя тень. Настройки стартовые, подбирать совместно по референсу и контрасту. Никаких ярких постоянных обводок или зелёных заливок.

Hero должен действительно показывать точки Земли через свободные области стекла, но не снижать читаемость данных. Внутренние таблицы/сообщения с чуть более плотной тёмной подложкой. Остальные секции сохраняют тот же материал; не требуется физическая рефракция или новые shaders для UI.

Если нужен backdrop-filter, ограничить blur примерно8–12px на крупных desktop surfaces, без вложенной многократной фильтрации. Не анимировать blur/shadow, без separate continuous RAF. Mobile/coarse и отсутствие поддержки: более плотная поверхность, blur0, одинаковый контраст. Не превращать «стекло» в дорогой эффект, от которого зависит смысл.

## 3. Hero и круглая Земля

Левая постоянная типографика/CTA, справа компактные задача/результат. Данные ближе к headings, без flex vertical centering в огромном пустом резерве. Шесть native selectors, mint underline активного, небольшая остановка/продолжение. На mobile можно перенести selectors в два ряда, не уменьшать targets ниже44px.

Земля только Hero. Континенты читаются серебристыми точками на более тёмных океанах; освещение края и глубина, без сетки, орбит и маршрутов. Силуэт в проекции КРУГЛЫЙ: равные диаметры X/Y; запрещён nonuniform CSS scale canvas. Размер renderer и aspect камеры соответствуют реальному прямоугольнику; resize обновляет camera, не растягивает Землю. Центр за серединой двух panels, круг полностью читается сверху/по бокам. Canvas pointer-events:none, не закрывает форму/вкладки.

Сохранить текущие seeded позиции. Континентальная маска/принадлежность вычисляется один раз из доступного локального географического источника или предварительно подготовленного asset; не загружать библиотеку/сетевые данные по каждому проходу и не генерировать geometry каждый кадр. Если достоверного источника/asset нет, сообщить MAIN перед заменой узнаваемой географии приблизительным рисунком.

Shader uniforms для медленного вращения, света и глубины. Не увеличивать particle count или создавать новую postprocessing цепочку. Сохранить один ticker, lazy WebGL, initial reduced без GPU, DPR≤1.5 desktop/≤1 mobile и cap30, offscreen/hidden stop, BFCache lifecycle/cleanup. CSS fallback — статичная круглая точечная Земля/маска, mobile слабее без pointer deformation. Картинка не доказывает FPS; физические устройства OPEN.

Первый высокий desktop viewport только Hero; min-block-size100svh как старт с border-box и естественным ростом содержимого. Arrow28–40px от нижнего края. Mobile/короткий desktop естественная высота. Без snap/pin/scroll hijacking.

Одна широкая стеклянная панель: десять selectors двумя рядами desktop; explanation≈28%, source→result≈72%. Mobile отдельная последовательность, без уменьшенной desktop-картинки. Compact readable controls и подписи каналов.

Прогресс тонкий, связан с полным15s demonstration и ручным запуском. Повтор/остановка небольшие, без счётчика и transport player. Glow один наружный overlay с мягким краем по всей панели; не clipped внутренним прямоугольником. Fine pointer только, reduced/touch без динамического glow. Наполненные сообщения/документы/таблицы с точным copy из JSON.
