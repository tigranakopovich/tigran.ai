## Взаимодействия и движение

- Click/Enter/Space запускают демонстрации. Одновременно одна активна. Новый запуск завершает прежнюю с корректным сохранённым результатом. Повтор той же кнопкой проверен.
- Проверены все три результата: заявка в таблице, сообщение о статусе, готовый документ. Реальных отправок и сервисных интеграций в примерах нет.
- Высота строки примера до/после запуска и геометрия общей области примеров этапов сохраняются.
- Выбор этапа проверен наведением, клавиатурным фокусом и нажатием; на mobile — нажатием. Основные описания всегда видимы.
- Проверены мобильное меню, Escape и возврат фокуса, якорь к контакту, видимый клавиатурный фокус кнопки. Поле бизнеса остаётся необязательным.
- Точки начала связей Hero совпадают с нижними краями карточек при парении и resize: ошибка измерения меньше 1 px. Геометрия обновляется через ResizeObserver, без постоянного JS-измерения layout.
- Hero: CSS-парение, последовательный однократный сигнал трёх входов и шагов. Кейс: однократный акцент. Фон: один медленный геометрический слой около Hero. Контакт неподвижен.
- Вне viewport декоративное движение останавливается. Остановка при скрытой вкладке проверена через симуляцию visibilitychange/document.hidden; настоящее переключение вкладки в ОС отдельно не проверялось. Демонстрация при скрытии приостанавливает таймер и продолжает при возврате.
- Reduced motion: нет активных анимаций; запуск примера сразу показывает итог; выбор этапа сохраняет статичное выделение. На mobile нет постоянного парения и фонового движения.

## Telegram — техническая готовность остаётся OPEN

Используется документированный формат личной ссылки `https://t.me/tigran_ai?text=...`: [Telegram — public username links](https://core.telegram.org/api/links#public-username-links). Ссылка обновляется при вводе и непосредственно перед переходом. Share-picker, копирование, другой чат или прямая ссылка без черновика не подставляются.

Проверены пустое поле и кириллическое значение «бухгалтерские услуги»: декодированный text точно совпадает с соответствующим шаблоном SPEC. Для обоих вариантов официальный t.me отвечает 200, показывает `Telegram: Contact @tigran_ai` и сохраняет полный UTF-8 черновик в `tg://resolve?domain=tigran_ai&text=...`. Сообщения не отправлялись.

| Клиент | Проверка |
| --- | --- |
| Форма в Chrome и переход через официальный t.me | Генерация обоих шаблонов и передача в tg-link подтверждены. Это не проверка поля ввода в Telegram. |
| Telegram Desktop на Windows | Приложение запущено, но UI-проверка не выполнена: computer-use дважды завершился с `windows sandbox failed: helper_unknown_error: setup refresh had errors`. |
| Авторизованный Telegram Web | Заполнение поля ввода не проверено. |
| Android / iOS | Реальные устройства и заполнение поля ввода не проверены. |

Полный сценарий нельзя считать принятым по проверке URL и t.me. Требуется подтверждение черновика в личном чате на перечисленных клиентах; вопрос остаётся OPEN для MAIN.
